# Security Policy

## Supported Versions
Currently, only the latest release of KubeGuard is supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability within KubeGuard, please DO NOT report it by opening a public issue. 
Instead, please send an email to the author privately.

- **Email**: [Author's contact email, e.g., via GitHub profile]

## Response Timeline
We will acknowledge your report within 48 hours and provide an estimated timeline for resolution and disclosure.

## Disclosure Policy
We will fix the vulnerability as quickly as possible. Once the fix is released, we will publicly disclose the vulnerability and the fix in our changelog and security advisories. We ask that you do not publicly disclose the vulnerability until the official fix is published.
